# 🐛 Bug Report — BR-005

## Title
Add to Cart button adds duplicate item

---

## Environment

| Field | Details |
|---|---|
| Device | Laptop |
| OS | Windows 11 |
| Browser | Firefox 125 |
| URL | `/product/:id` |

---

## Steps to Reproduce

1. Open any product page
2. Click **"Add to Cart"** exactly **once**

---

## Expected Result

Exactly **1 item** is added to the cart.

---

## Actual Result

**2 items** are added to the cart automatically after a single click.

---

## Severity

🟡 **Medium** — Users are unintentionally charged for extra items. Creates trust issues.
