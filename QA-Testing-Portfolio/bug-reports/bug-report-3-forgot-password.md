# 🐛 Bug Report — BR-003

## Title
Forgot password link opens blank page

---

## Environment

| Field | Details |
|---|---|
| Device | Laptop |
| OS | Windows 11 |
| Browser | Microsoft Edge |
| URL | `/login` → click "Forgot Password?" |

---

## Steps to Reproduce

1. Open the login page
2. Click the **"Forgot Password?"** link

---

## Expected Result

User is redirected to the password reset page with an input field for their email.

---

## Actual Result

A completely blank page is displayed.

---

## Severity

🟡 **Medium** — Users who forget their password cannot recover their account.
