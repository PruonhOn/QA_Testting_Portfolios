# 🐛 Bug Report — BR-010

## Title
Logout button redirects to error page

---

## Steps to Reproduce

1. Log in with a valid account
2. Navigate to any page after login
3. Click the **Logout** button

---

## Expected Result

User is logged out and redirected to the homepage or login page.

---

## Actual Result

An error page is displayed instead of the expected redirect.

---

## Severity

🟡 **Medium** — Users are confused after logout. Session may not be properly cleared.
