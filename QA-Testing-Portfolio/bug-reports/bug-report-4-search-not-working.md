# 🐛 Bug Report — BR-004

## Title
Search bar does not show results

---

## Environment

| Field | Details |
|---|---|
| Device | Laptop |
| OS | Windows 11 |
| Browser | Chrome 124 |
| URL | `/` (Homepage) |

---

## Steps to Reproduce

1. Open the homepage
2. Click on the search bar
3. Type a known product name (e.g., "Laptop")
4. Press **Enter**

---

## Expected Result

A list of relevant search results matching the product name is displayed.

---

## Actual Result

No results are shown — even when the product is confirmed to exist in the catalog.

---

## Severity

🔴 **High** — Search is a core discovery feature. Broken search prevents users from finding products.
