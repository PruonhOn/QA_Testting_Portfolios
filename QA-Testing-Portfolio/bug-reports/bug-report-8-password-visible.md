# 🐛 Bug Report — BR-008

## Title
Password field shows plain text

---

## Steps to Reproduce

1. Open the login page
2. Click on the **Password** field
3. Type any password

---

## Expected Result

Password characters are masked with dots (••••••••) for security.

---

## Actual Result

Password is displayed as **plain visible text** while typing.

---

## Severity

🔴 **High** — Security vulnerability. Anyone nearby can see the user's password on screen.
