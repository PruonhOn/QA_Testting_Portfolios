## 🔍 Sample Bug Report Format

Every bug report in this portfolio follows a consistent structure:

```markdown
Title: [Short description of the bug]

Environment:
- Device: [Laptop / Phone / Tablet]
- OS: [Windows / macOS / Android / iOS]
- Browser: [Chrome / Firefox / Edge / Safari]

Steps to Reproduce:
1. [Step 1]
2. [Step 2]
3. [Step 3]

Expected Result:
[What should happen]

Actual Result:
[What actually happened]

Severity: [High / Medium / Low]
```
